# 設定傳遞範本

行銷部門製作傳遞範本，以便標準化創意外觀和風格，從而更快速地執行和啟動行銷活動。

範本可系統地包括：

* 類型
* 寄件者和回覆地址
* 基本個人化區塊
* 鏡像頁面和取消訂閱的連結
* 內容、公司標誌或簽名
* 其他傳遞屬性，例如資源有效性、批次數量⋯
